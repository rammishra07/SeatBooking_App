# SeatBooking

MERN event seat-booking application for a technical assessment.

## Workspaces

- `client/` — Vite + React frontend
- `server/` — Node.js + Express backend

## Setup

Copy each `.env.example` file to `.env` and provide local values before running either workspace. MongoDB must be configured as a replica set before transactional booking work is added.

## Current status

Project scaffolding only. Authentication, database models, API routes, and UI features have not been implemented yet.
